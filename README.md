# UGI CCBA Website

## Overview
This project is the official website for the Unidad de Gestión Integral del Club Ciudad de Buenos Aires (UGI CCBA). It serves as a platform to provide information about the club's programs, purpose, and resources.

## Project Structure
```
ugiccba-site
├── assets
│   ├── fonts          # Directory containing font files for typography
│   └── icons          # Directory containing icon files for visual elements
├── index.html         # Main HTML document for the website
├── styles.css         # CSS styles defining the layout and appearance
├── script.js          # JavaScript file for interactivity and DOM manipulation
└── README.md          # Documentation for the project
```

## Getting Started

### Prerequisites
- A web server to host the website (e.g., Apache, Nginx)
- A domain name (e.g., www.ugiccba.com.ar)

### Installation
1. Clone the repository or download the project files.
2. Upload the project files to your web server.
3. Ensure that the directory structure is maintained.

### Deployment
- Point your domain (www.ugiccba.com.ar) to the directory where the `index.html` file is located.
- Access the website through your domain in a web browser.

## Usage
- Open `index.html` in a web browser to view the website.
- Modify `styles.css` to change the appearance of the website.
- Update `script.js` to add or modify interactivity.
